# Radar Industrial — aplicação web gratuita

Portal público de notícias industriais para Portugal, França, Espanha, Marrocos e Tunísia. Inclui layout responsivo, filtros, pesquisa, PWA instalável e recolha diária de RSS.

## Publicar com GitHub Pages
1. Em Settings → Pages, escolhe GitHub Actions como método de publicação.
2. No separador Actions, executa manualmente primeiro “Recolher notícias RSS”; depois “Publicar Radar Industrial”.
3. O endereço será https://NunoRosa2020.github.io/radar-industrial/.

## Atualização automática
A recolha corre diariamente às 05:17 UTC (aproximadamente 05:17 em Portugal no inverno e 06:17 no verão). O GitHub pode atrasar execuções agendadas.

## Limitações
- Google News RSS é um agregador público, não uma fonte oficial nem uma API com garantia de disponibilidade.
- A classificação por país e setor é baseada na pesquisa e em palavras-chave; pode conter erros. Confirma sempre a fonte original.
- O resumo é texto do feed e pode estar incompleto. O site não faz verificação factual independente.
- Uma notícia de investimento não significa que a empresa esteja à procura de moldes ou fornecedores.
- Não são inventadas notícias. Se os feeds não devolverem resultados, o site mostra um estado vazio.
- O objetivo é manter o projeto em 0 €/mês com serviços gratuitos; os limites e condições dos fornecedores podem mudar.

## Instalar no telemóvel
Depois de publicado, abre o endereço no Chrome/Edge e usa “Instalar aplicação” ou “Adicionar ao ecrã principal”, se disponível.
